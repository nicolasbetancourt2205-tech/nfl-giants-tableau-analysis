# NFL Giants Performance Analysis

Sports analytics project analyzing NY Giants performance data using Tableau.

## Overview
Visual analysis of NY Giants game and player performance data, exploring key metrics such as scoring trends, offensive and defensive stats, and game outcomes.

## Tools Used
- Tableau (data visualization and dashboard)
- Dataset: NFL Giants historical performance data

## Key Insights
- Analysis of offensive and defensive performance trends
- Game outcome patterns across seasons
- Player performance metrics visualization
